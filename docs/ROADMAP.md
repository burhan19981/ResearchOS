# Roadmap

These are proposed directions, not delivery promises or implemented features.

1. Reproducible Python dependency constraints and portable packaging of migration/configuration assets.
2. Authentication and authorization before any shared deployment, verified approval identity, and private security reporting.
3. Explicit live-source/provider compatibility checks and careful evaluation of generated research suggestions.
4. Pagination and clearer empty states in the dashboard; generation actions only after their approval and privacy boundaries are designed.
5. Domain-specific dataset validators and a documented real experiment example using openly licensed data.
6. Stronger execution isolation and lifecycle controls before considering remote/container execution.
7. A higher-level orchestration layer built on existing services, with human review and evidence provenance preserved.

ResearchOS does not yet demonstrate these capabilities at production scale. Prioritize concrete issues and reproducible examples over adoption claims.
