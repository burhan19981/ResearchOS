# Third-party material and licensing

The project imports Python and npm packages; their own licenses continue to apply. A project license does not relicense dependencies, literature, datasets, model outputs, or third-party assets. No private database, research dataset, model weights, or paper PDFs are included in the release candidate.

The frontend npm lockfile records dependency license metadata. Python distribution metadata can be inspected in the installed environment. Release review must retain upstream notices if dependencies or their assets are bundled/distributed; this source-only candidate excludes installed packages and compiled frontend output.

Unused starter SVG artwork was excluded because its provenance was not established. Test fixtures contain synthetic records and public bibliographic identifiers; they are not evidence of research results or adoption. The owner has confirmed ownership of the project material and approved Apache-2.0. License metadata and automated inspection alone cannot prove ownership or rule out copied material.
